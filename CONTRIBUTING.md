# Contributing to Cocoa — Managing Expenses by Cocoa

Thank you for exploring or contributing to **Cocoa**!

## How to Publish This Repository to Your GitHub Account (3 Commands)
1. Create a new repository on GitHub (e.g., `cocoa-expense-manager`).
2. Open a terminal inside this folder on your laptop and run:
   ```bash
   git remote add origin https://github.com/<your-username>/cocoa-expense-manager.git
   git branch -M main
   git push -u origin main
   ```
3. As soon as you push:
   - **GitHub Actions** will automatically compile `Cocoa-Managing-Expenses.apk` and publish it under **Releases** for your Android smartphone.
   - **GitHub Pages** will deploy `docs/index.html` as a live interactive web app for your laptop and desktop.
